# Historical renderings

These committed renderings predate the current source-label and sparse-calibration presentation. They are retained as historical artifacts, not restamped or used as the current BMC supporting figures. Run `scripts/build_bmc_submission.py` to regenerate the current scientific tables and figures through the builders. The explicit public archive inventory excludes this directory; current generated payloads are separately listed in that inventory and hashed in the build manifest. No software rendering establishes biological validation.
